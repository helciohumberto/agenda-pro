# User stories

1. Como dona, quero me cadastrar e criar meu negócio, para digitalizar
   minha agenda e ficar mais automatizado, com clientes, funcionários
   e eu vendo os mesmos horários disponíveis e indisponíveis.
2. Como dona, quero convidar um funcionário por email, para garantir
   que ele já entre vinculado ao meu negócio certo, sem risco de criar
   conta solta ou errada.
3. Como cliente, quero informar meu nome e contato ao marcar, para
   agendar rápido sem precisar criar senha e conta completa.
4. Como cliente, quero ver os horários livres de um serviço, para não
   precisar ligar perguntando se tem vaga.
5. Como cliente, quero marcar um horário escolhido, para garantir o
   agendamento sem depender de alguém responder minha mensagem.
6. Como cliente, quero cancelar meu próprio agendamento, para liberar
   o horário sem precisar ligar avisando a dona.
7. Como dona, quero cancelar um agendamento de qualquer cliente, para
   manter a agenda certa quando o cliente avisa por telefone/WhatsApp
   em vez de usar o sistema.
8. Como cliente, quero receber um lembrete por email antes do horário,
   para não esquecer do compromisso.
9. Como dona, quero que o sistema recuse marcar dois agendamentos no
   mesmo horário com o mesmo profissional, para não perder cliente por
   engano de agenda duplicada.
